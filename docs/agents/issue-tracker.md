# Issue tracker

Use GitHub Issues in `wagar-meilech/zoetrope` for specs and implementation tickets. The user approved this tracker and enabling Issues in `docs/IMPLEMENTATION-REVIEW.md` on 23 October 2026.

- Ready for implementation: `ready-for-agent`.
- Track blocking issue relationships in each issue body and the task-graph document.
- Integrate on one feature branch and close the spec and tickets through the integration PR.
- Do not merge the PR into main unless the user requests it.
- PRs as an external request surface: off.

The current feature is described in `docs/GOAL-CONSOLE-SPEC.md` and `docs/GOAL-CONSOLE-TICKETS.md`. The approved test seams are the public console and executable/external-launch interfaces.
