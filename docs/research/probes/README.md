# Archived public-interface probes

These Rust sources reproduce inventory/placement, refresh, sensitive-answer,
paste, delayed-copy and save-pressure observations through public console and
Store interfaces. They were moved from temporary storage to preserve the final
review evidence. Read [the final review](../zoetrope-final-review-2026-10-25.md)
and [fix notes](../zoe-review-fixes-implementation.md) for the results and which
observations were superseded by fixes.

Maintained regression coverage lives under the repository's `tests/` directory.
These historical sources may assume the original machine's paths and build
artifacts; their compiled executables are local-only under
`.local/research-artifacts/tmp/` at the repository root.
