Connect the project's maintained task artifacts to Zoetrope's local Work graph.
Installing or discovering this skill alone is not project opt-in.

For coordinator setup, resumed work, source changes or disable, read
[project setup](references/project-setup.md). It covers authorization, exact
identity, the managed project pointer and local disable precedence.

For choosing or adapting task artifacts, read
[structured sources](references/sources.md). Prefer the existing tracker and
add only fields the importer needs. Matt Pocock workflows integrate through
the project's tracker instructions; upstream skills stay unchanged.

Workers keep their assigned task's normal status, owner and declared dependencies
current at meaningful transitions. Once a supported source is bound, normal edits
refresh locally without per-item JSON reports or coordinator prompts. Children
need only their assigned artifact and the project's ordinary tracker convention;
they need not repeat setup or load the full reporting guide.

Source status is reported work. Verify outcomes separately using actual evidence.
For optional context or outcomes absent from the source schema, read
[supplemental reporting](references/reporting.md) only when needed.
